## Features

- Scan a printed photo and add a video to it.
- Store markers on the device.
- Fit or crop the video to the photo.
- Manage and delete markers.
- Share or import markers as `.lily` files.

## Development

Lily needs a native development build. It does not run in Expo Go.

Requirements: Node.js, pnpm, Xcode for iOS, and Android Studio for Android.

```sh
pnpm install
pnpm exec expo prebuild
pnpm exec expo run:ios       # or: pnpm exec expo run:android
pnpm exec expo start --dev-client
```

The native projects are generated by Expo and are not committed to the repository. Run `expo prebuild` again after changing native configuration.

Useful checks:

```sh
pnpm exec tsc --noEmit
pnpm lint
```

## Project layout

- `app/` — Expo Router entry points.
- `components/marker/` — marker scanning, creation, and management UI.
- `components/viro/` — AR scene and tracked video components.
- `data/markers.ts` — local marker storage.
- `data/lilyPackage.ts` — `.lily` export and import format.
- `input/` — sample photo and video files.

Add markers from the app using the `+` button. They are copied into the app's local storage.

## CI

GitHub Actions has two workflows:

- `CI` runs on commits and pull requests. It type-checks, lints, and builds Debug APK and IPA-shaped artifacts.
- `Release builds` runs when a GitHub Release is published. It builds Release APK and IPA-shaped artifacts and attaches them to the release.

The iOS artifacts are regular `Payload/*.app` zips with an `.ipa` extension. They are useful for checking the builds, but they are not installable on an iPhone until signed with an Apple certificate and provisioning profile. Renaming an unsigned zip cannot bypass iOS code signing.
